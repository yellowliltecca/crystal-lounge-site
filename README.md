# CRYSTAL Lounge — сайт заведения

Готовый адаптивный статический сайт на HTML, CSS и JavaScript.

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере.

Для публикации можно загрузить содержимое папки на GitHub Pages или другой статический хостинг.

## Что внутри
- `index.html` — структура сайта и тексты;
- `styles.css` — адаптивный дизайн;
- `script.js` — мобильное меню и просмотр фотографии;
- `assets/` — пять предоставленных фотографий, оптимизированных в WebP, и favicon.
